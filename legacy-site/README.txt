Put your images in this folder with these exact filenames so the site picks them up automatically:

HERO SLIDER (recommended size: 1600x900px or larger, landscape)
  slide1.jpg
  slide2.jpg
  slide3.jpg

ABOUT SECTION (portrait photo, recommended 800x1000px)
  artist.jpg

GALLERY (square images work best, recommended 600x600px)
  gallery1.jpg
  gallery2.jpg
  gallery3.jpg
  gallery4.jpg
  gallery5.jpg
  gallery6.jpg

Notes:
- You can add more slides: just add slide4.jpg, slide5.jpg etc. in the HTML
  (copy a <div class="slide">...</div> block in index.html and add the img tag),
  the slider JS will automatically detect the new slide count.
- Keep image file sizes reasonably small (compress via tinypng.com or similar)
  so the homepage loads fast.
- If a filename doesn't match exactly (case-sensitive on live servers), the
  image will show broken.
